# 🍺 МастерВарка — Калькулятор и Лаборатория Пивовара

Профессиональное веб-приложение для домашних и крафтовых пивоваров. Включает комплексный калькулятор варки, умный подбор рецептов по остаткам в кладовой, ИИ-генератор названий и дизайн-студию этикеток, календарь брожения, журнал варок, базу лайфхаков, поддержку стандартов BJCP, экспорт в BeerXML и PDF, а также облачную синхронизацию и офлайн-режим.

---

## 🌟 Основные возможности

### 1. 🧪 Пивоваренный калькулятор и конструктор рецептов
* **Засыпь солода:** точный расчет начальной плотности (OG в SG и градусах Плато °P) с учетом экстрактивности солодов и эффективности варочника (Brewhouse efficiency).
* **Цветность пива:** расчет по формуле Мори (Morey SRM / EBC) с динамической визуализацией реального оттенка в бокале пива с пенной шапкой.
* **Водоподготовка:**
  * Расчет воды на затирание (Strike water) и промывочной воды (Sparge water).
  * Автоматический расчет **температуры воды для засыпи зерна (Strike Water Temp)** на основе гидромодуля и начальной температуры зерна.
* **Температурные паузы затирания (Mash Schedule):**
  * Полный контроль температурных пауз: кислотная (35–45°C), белковая (50–55°C), мальтозная (62–65°C), декстриновая (68–72°C), мэшаут (78°C).
  * Пресеты профилей затирания: «Сухое тело», «Сбалансированное», «Полнотелое», «Баварское пшеничное», «Ступенчатое классическое».
* **Охмеление и кипячение:**
  * Расчет горечи IBU по классической формуле Гленна Тинсета (Glenn Tinseth) с учетом времени кипячения, альфа-кислоты и плотности сусла.
  * Поддержка стадий охмеления: кипячение (60/30/15 мин), вирпул (Whirlpool / Flameout) и сухое охмеление (Dry Hopping).
  * Расчет баланса горечи **BU:GU** (соотношение единиц горечи к гравитационным единицам плотности).
* **Дрожжи и норма засева (Pitch Rate):**
  * Расчет необходимого количества дрожжевых клеток (миллиарды клеток) для элей, лагеров, пшеничных сортов и квейков.
  * Точный расчет нормы сухих дрожжей (в граммах и стандартных пакетиках 11.5 г).
* **Карбонизация и расчет праймера:**
  * Расчет декстрозы (глюкозы), столового сахара (сахарозы), сухого экстракта (DME) и молодого сусла (шпайзе / Speise) на литр и на всю партию в зависимости от температуры розлива и целевого объема CO2.
  * Рекомендации по срокам выдержки (14–21 день в тепле, созревание в холоде).
* **Валидация по стилям BJCP:**
  * Сверка показателей партии (OG, FG, ABV, IBU, EBC, BU:GU) с официальным руководством Beer Judge Certification Program.
  * Практические советы пивовару по балансировке рецепта.
* **Масштабирование партии (Scale Batch):**
  * Изменение объема варки (10, 20, 30, 50, 100 л или произвольный объем) в один клик с пропорциональным пересчетом солодов и хмелей с сохранением исходной плотности и горечи.

---

### 2. 🔍 Подбор рецептов по ингредиентам («Что сварить из остатков?»)
* **Кладовая пивовара (Pantry Inventory):** учет остатков солодов, хмелей, дрожжей и добавок.
* **Умный алгоритм сопоставления:**
  * **100% совпадение:** рецепты, которые можно сварить прямо сейчас из имеющихся запасов.
  * **Частичное совпадение (от 60%):** наглядный расчет того, что уже есть, и блок «Что докупить / добавить» с точным указанием недостающих граммов или килограммов.
* Фильтры по стилям, категориям и поиск по названию или сорту хмеля.

---

### 3. 📚 База рецептов и личные коллекции
* Предустановленный каталог признанных мировых стилей BJCP (Czech Pilsner, American IPA Citra, Bavarian Weissbier, Oatmeal Stout, Belgian Tripel и др.).
* Создание, редактирование и сохранение авторских рецептов в базу.
* Личные коллекции: «Все», «Избранное ⭐», «Планирую сварить 📌», «Мои авторские рецепты 🛠️».
* Полнотекстовый поиск по стилям, ключевым словам и ингредиентам.

---

### 4. 🎨 ИИ Лаборатория & Студия дизайна этикеток
* **Интеграция с Google Gemini AI:**
  * Генерация 3 вариантов креативных крафтовых названий пива.
  * Генерация звучного слогана и легенды для контрэтикетки.
  * Профессиональный совет технолога для конкретного стиля и рецепта.
  * Экспертный аудит рецепта по канонам BJCP с гастрономическими сочетаниями (food pairings), рекомендуемой температурой подачи и формой бокала.
* **Интерактивный Canvas-редактор этикетки:**
  * Стили оформления: *Craft Modern*, *Vintage Monastery*, *Minimal Nordic*, *Botanical*, *Retro Arcade*.
  * Выбор эмблем (хмель, колос, бочка, корона, горы).
  * Настройка палитры (фон, текст, акцент, рамка).
  * **Скачивание готовой этикетки высокого разрешения (PNG 800×500 px)** для печати на самоклеящейся бумаге.

---

### 5. 📅 Календарь брожения & Сроки выдержки
* Автоматическое построение таймлайна партии:
  1. День варки (Brew Day)
  2. Главное брожение (Primary Fermentation)
  3. Сухое охмеление (Dry Hopping Alert)
  4. Окончание брожения, розлив и внесение праймера
  5. Карбонизация в бутылках при комнатной температуре
  6. Холодное созревание / лагеризация (Cold Conditioning / Lagering)
  7. Готово к дегустации!
* Отслеживание текущего дня, оставшегося времени, статусов этапов и напоминаний о действиях пивовара.

---

### 6. 📝 Журнал варок & Дегустационный дневник
* Запись замеров дня варки: плановая vs фактическая OG, плановая vs фактическая FG, расчет реального ABV, pH затора.
* Оценка готового пива по 50-балльной системе BJCP:
  * Аромат (до 12 баллов)
  * Внешний вид и пена (до 3 баллов)
  * Вкус (до 20 баллов)
  * Тело и текстура (до 5 баллов)
  * Общее впечатление (до 10 баллов)
* Фиксация заметок об успехах и ошибках варки.

---

### 7. 💡 Лайфхаки пивоварения
* Подборка полезных советов от опытных домашних мастеров: борьба с холодным помутнением (Cold Break), техника Whirlpool, защита от окисления при сухом охмелении, правильная температура промывочной воды, варка сиропа декстрозы.
* Голосование за полезность советов («Помогло! 👍»).
* Возможность публикации собственного авторского лайфхака.

---

### 8. 👥 Социальная лента пивоваров
* Публикация отчетов о готовых варках с фотографиями пива в бокале.
* Обсуждение рецептов, комментарии, обмен опытом и лайки.

---

### 9. 🖨️ Экспорт в PDF & BeerXML 1.0
* **Печать в PDF (Printable Brew Sheet):** сверстанный структурированный варочный лист формата A4 с чек-листом, таблицей засыпи, температурами и полями для отметок ареометра.
* **BeerXML 1.0:** стандартный экспорт и импорт файлов `.xml` (полная совместимость с BeerSmith, Brewfather, Grainfather).
* **JSON Backup:** полное сохранение и восстановление всей базы данных в один клик.

---

### 10. ☁️ Облачная синхронизация & Офлайн-режим
* Синхронизация между устройствами (телефон, ноутбук, планшет) по персональному 6-значному коду.
* Полная работа в автономном режиме (**Offline-First**) с автоматическим сохранением в локальном хранилище браузера.

---

### 11. 🌓 Темы оформления
* Тёмная тема: уютная атмосфера крафтового паба с теплыми янтарными тонами.
* Светлая тема: лаконичный интерфейс современной исследовательской лаборатории.

## 🛠️ Стек технологий

* **Frontend:** React 19, TypeScript, Tailwind CSS v4, Lucide React Icons, HTML5 Canvas API
* **Backend:** Node.js, Express, Vite middleware mode
* **ИИ:** Google Gemini API (`@google/genai` SDK, модель `gemini-3.8-flash`)
* **Стандарты:** BeerXML 1.0, BJCP Style Guidelines

## 🚀 Установка и запуск

1. **Клонирование репозитория:**
   ```bash
   git clone https://github.com/pippopil/-.git
   cd -
   ```

2. **Установка зависимостей:**
   ```bash
   npm install
   ```

3. **Настройка переменных окружения:**
   Скопируйте `.env.example` в `.env` и укажите ключ Gemini API при необходимости:
   ```env
   GEMINI_API_KEY="ВАШ_КЛЮЧ_GEMINI_API"
   ```

4. **Запуск в режиме разработки:**
   ```bash
   npm run dev
   ```
   Приложение будет доступно по адресу `http://localhost:3000`.

5. **Сборка для продакшена:**
   ```bash
   npm run build
   npm start
   ```
