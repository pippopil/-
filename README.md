# 🍺 МастерВарка — Цифровая Лаборатория и Калькулятор Пивовара

> Полнофункциональная кроссплатформенная среда для домашних и крафтовых пивоваров. 
> Включает калькулятор варки с BJCP-валидацией, справочник всех сортов Курского солода с поиском аналогов, импорт рецептов из BeerSmith и Бир.РФ, офлайн-генератор этикеток, облачную синхронизацию и ведение журнала варок.

## 🚀 Быстрый старт для новичка

Если вы варите пиво в первый раз или хотите быстро рассчитать свою первую партию:

1. **Шаг 1. Выберите стиль в «Рецептах»**:
   - Перейдите во вкладку **«Рецепты»** и выберите базовый стиль (например, *«Американский Pale Ale»* или *«Баварский Вайсбир»*). Нажмите **«Загрузить в калькулятор»**.
2. **Шаг 2. Настройте засыпь солода и гидромодуль**:
   - Во вкладке **«Калькулятор»** укажите объем вашей варки (например, 20 литров) и эффективность оборудования (по умолчанию 75%).
   - Добавьте базовый солод (например, *Курский Пилснер* или *Pale Ale*) и карамельный солод для цвета и тела. Калькулятор автоматически пересчитает начальную плотность (**OG**) и цвет (**EBC**).
3. **Шаг 3. Охмеление и расчет горечи (IBU)**:
   - Введите хмель на горечь (за 60 минут до конца кипячения) и на аромат (за 5-10 минут или в вирпул). Формула Гленна Тинсета мгновенно покажет баланс горечи к сладости (**BU:GU**).
4. **Шаг 4. Водный баланс и паузы затирания**:
   - В блоке *«Вода и Затирание»* проверьте объем заторной и промывочной воды. Калькулятор рассчитает точную температуру воды первого залива (**Strike Temp**) с учетом охлаждения от холодного зерна.
5. **Шаг 5. Распечатайте варочный лист или ведите таймер**:
   - Нажмите кнопку **«PDF»** в верхнем меню, чтобы получить аккуратный чек-лист для кухни/пивоварни, или откройте **«Журнал варок»**.
6. **Шаг 6. Создайте авторскую этикетку**:
   - Перейдите во вкладку **«ИИ Этикетки»**, выберите художественную тему и сгенерируйте концепт этикетки с палитрой, слоганом и историей сорта!

## ❓ Часто задаваемые вопросы (FAQ)

### ❓ Как импортировать рецепт из BeerSmith?
> В верхнем меню нажмите кнопку **«BeerXML»**. Выберите **«Импорт .xml / .json»** и укажите файл, экспортированный из BeerSmith, Promash или Grainfather. Все солода, хмели, дрожжи и температурные паузы мгновенно перенесутся в калькулятор.

### ❓ Как загрузить рецепт напрямую по ссылке с Бир.РФ?
> Нажмите **«BeerXML»** → вкладка **«Импорт по URL / Бир.РФ»**. Вставьте прямую ссылку на страницу рецепта (например, `https://xn--90aoy.xn--p1ai/recipes/...`). Сервер безопасно загрузит данные и автоматически распарсит засыпь, профиль воды и хмель в проект.

### ❓ Работает ли приложение и генератор этикеток без интернета?
> **Да!** МастерВарка — это полноценное PWA. Приложение полностью кэшируется в браузере и работает в гараже или подвале без сети. Для генерации этикеток и аудита рецептов встроен **автономный генератор**, создающий описания и палитры со 100% точностью даже в авиарежиме (0 токенов).

### ❓ Как синхронизировать рецепты между компьютером и телефоном?
> В верхнем меню нажмите **«Синхронизация»**. На первом устройстве нажмите **«Сохранить в облако»** — появится 6-значный буквенно-цифровой код (например, `BREW-8492`). Введите этот код на втором устройстве в поле **«Загрузить по коду»** — все ваши рецепты и склад мгновенно обновятся.

## 📱 Установка и запуск

### 1. Мобильная установка (PWA)
Откройте приложение в мобильном браузере:
- **Android (Chrome):** Нажмите всплывающую плашку или в меню браузера выберите *«Добавить на главный экран»*.
- **iOS (Safari):** Нажмите кнопку *«Поделиться»* (квадрат со стрелкой вверх) → *«На экран Домой»*.

### 2. Сборка .APK для Android через Capacitor
В репозитории уже собрана папка `android/`:
```bash
# 1. Установка зависимостей
npm install

# 2. Сборка веб-части и синхронизация
npm run cap:android

# 3. Открытие в Android Studio
npm run cap:open
```
В Android Studio выберите: **Build → Build Bundle(s) / APK(s) → Build APK(s)**.

## 🔒 Безопасность

- **SSRF Guard:** Серверный роут `/api/recipes/fetch-url` валидирует хосты и защищен от обращения к приватным IP-диапазонам (RFC 1918), loopback (`127.0.0.1`, `localhost`) и облачным метаданным провайдеров (`169.254.169.254`).
- **Строгий лимит тела запроса:** Лимит `express.json` ограничен до 5 МБ для предотвращения атак исчерпания памяти.
- **Безопасное хранение ключей:** API-ключи Gemini хранятся только в серверном окружении (`.env`) и не попадают в клиентскую сборку.
